A single funny sentence for the make.fun "The One-Line Laugh" bounty: one line, at most 200 characters, built on an everyday truth — cleaning your room to find motivation — with a small surprise at the end.

## The line

> I finally cleaned my room to find my motivation, and all I found was a charger for a phone I haven't owned since 2019.

## How it works

`main.py` (Python 3, standard library only) writes the line to `/output/entry.txt`, asserts it is a single line of 1–200 characters, then re-reads the file to verify exactly what was written.

```sh
python3 main.py
```
